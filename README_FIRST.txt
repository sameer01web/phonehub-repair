PHONE HUB — READ THIS FIRST

1. Extract this ZIP.
2. Open the PHONE_HUB_SINGLE_SHOP folder itself in Antigravity.
3. Confirm package.json is visible in the root.
4. Run npm install.
5. Copy .env.example to .env and add Supabase URL + anon key.
6. Run supabase/migrations/001_phone_hub_single_shop.sql in Supabase SQL Editor.
7. Run npm run dev.

IMPORTANT: This is a real React project and a functional MVP foundation, not a fully completed production ERP. Read README.md for implemented modules and remaining work.
